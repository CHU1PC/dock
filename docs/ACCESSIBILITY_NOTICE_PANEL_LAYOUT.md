# アクセシビリティ注記と Dock パネルの配置

GitHub issue #182 に対応し、アクセシビリティ未許可時の注記がゴミ箱をパネル外へ押し出さないようにする。

## 変更内容

通知バッジのアクセシビリティ許可がなく、アプリ項目を含む場合に表示する注記の幅を320ポイントに制限する。パネル幅は Dock の項目列と注記の幅の大きい方を基準にし、パネル内にゴミ箱と注記を収める。

## 仕様判断

- Dock の項目列の長さは従来どおり維持し、注記が必要な場合だけ、パネル幅を注記幅以上に広げる。
- Dock の項目列が注記より長い場合は、注記を320ポイント内で折り返す。
- パネル幅の計算を `DockPanelSizing.size` に集め、幅と高さを単体テストで確認する。

## 受け入れ条件との対応

| 条件 | 状況 | 根拠 |
|---|---|---|
| Accessibility 許可がなくても、ゴミ箱を常にパネル内に表示する | 未確認 | 複数のアイコンサイズと項目数について、注記の有無にかかわらずゴミ箱の右端がパネル幅内に収まることを単体テストで確認した。実画面での表示は未確認 |

## 未検証

- Accessibility 許可を外した実画面でのゴミ箱の表示、ドラッグ、右クリック。
- 左右配置、複数ディスプレイ、最大項目数での実画面表示。
- macOS のバージョン差による注記の折り返し。

## 撮影の手順

撮影する場合は専用ヘッドレス macOS VM を使い、ホストには Dock Studio を表示しない。

### 検証用データ

ゲストで `/Users/Shared/dock-182` を作り、アプリ項目とフォルダ項目を含む `profiles.json` を置く。設定は下配置、アイコンサイズ52とする。Dock Studio を `DOCKSTUDIO_DATA_DIR=/Users/Shared/dock-182` で起動し、Dock Studio の Accessibility 許可を無効にする。

### 操作と期待結果

1. 管理ウィンドウを「設定」タブにして、デスクトップ用パネルを表示する。
2. 注記が項目列の上に折り返して表示され、ゴミ箱が項目列の末尾でパネル内に収まることを確認する。
3. ファイルをゴミ箱へドラッグし、ゴミ箱の右クリックメニューを開く。
4. 注記とゴミ箱が見える静止画と、ドラッグ操作の動画を保存する。

予定する画像と動画は、`docs/media/accessibility-notice-panel-layout/` に保存する。
