# フォルダ内容の Automatic 表示

## 変更内容

フォルダ内容の表示形式に「自動」を追加した。選択はフォルダごとに保存され、従来の「リスト」「グリッド」「Fan」も選べる。

## 仕様判断

Automatic の選択は、項目数と Dock の配置だけを受け取る純粋関数で決める。現在の DockStudio の表示制約を使い、下配置では1〜8件を Fan、9件以上を Grid、項目がない場合を List にする。左または右配置では件数にかかわらず List にする。

この条件は DockStudio の実装上の方針であり、標準 Dock の選択条件を再現したものとは確認できていない。Automatic は選択肢として保存し、フォルダを開くたびに現在の項目数と配置から表示形式を決める。明示した表示形式は自動判定で上書きしない。旧プロファイルの Grid 設定も読み込み時に維持する。

## 受け入れ条件との対応

| 条件 | 状況 |
| --- | --- |
| 標準 Dock の Automatic が項目数と配置から表示形式を選ぶ条件を記録する | 未確認。標準 Dock の実画面を観察していない |
| フォルダごとに Automatic を選択・保存し、条件に応じて形式を選ぶ | 一部のみ。保存形式、件数と配置による選択、旧 Grid 設定の互換性を単体テストで確認した。VM での保存後の再起動は未確認 |
| 明示した Fan・Grid・List を維持し、Automatic に切り替えた後の項目操作を確認する | 一部のみ。既存形式を維持する分岐と自動選択を単体テストで確認した。実画面の選択、開く操作、キーボード操作は未確認 |

## 自動テストとビルド

ホストでは指定スクリプトで単体テストとビルドを実行する。GUI は表示しない。

| 確認 | 結果 |
| --- | --- |
| `/private/tmp/cw/run-check.sh 71 test` | 341件、失敗0件 |
| `/private/tmp/cw/run-check.sh 71 release` | `BUILD SUCCEEDED` |
| `/private/tmp/cw/run-check.sh 71 testbuild` | `TEST BUILD SUCCEEDED` |

Automatic の件数境界、配置別の選択、Automatic 値の保存と、旧 Grid 設定の読み込みを単体テストで確認する。

## 未検証

- 標準 Dock の Automatic が実際に選ぶ形式と、その項目数の境界。
- macOS のバージョンごとの動作差。
- VM 上での形式の保存、再起動後の復元、表示、項目を開く操作、キーボード操作。
- 画面端や左右配置での実際のポップオーバー位置と操作性。

## 撮影の手順

専用のヘッドレス macOS VM または検証用 Mac のゲストで行う。普段使いのホストではアプリや検証画面を表示しない。標準 Dock と DockStudio の比較には、同じ macOS バージョン、画面解像度、拡大率を使う。

### 検証用データ

ゲストで `/Users/Shared/dockstudio-71` を作る。`profiles.json` に、項目数の違うフォルダを下、左、右の各配置で試せるフォルダ項目として登録する。各フォルダには1件、8件、9件、および空のケースを作る。名前と種類が分かるように、アプリ、ファイル、サブフォルダを混ぜる。

Release 成果物をゲストに置き、次で起動する。

```sh
DOCKSTUDIO_DATA_DIR=/Users/Shared/dockstudio-71 /path/to/DockStudio.app/Contents/MacOS/DockStudio
```

### 操作と確認項目

1. DockStudio のフォルダを開き、表示形式から Automatic を選ぶ。フォルダを閉じて再度開き、Automatic が選ばれたままか確認する。
2. 空、1件、8件、9件のフォルダを下配置で開き、実際に選ばれた表示形式を記録する。
3. 同じ件数のフォルダを左配置と右配置で開き、選ばれた形式、項目の表示、ポップオーバーの画面内への収まりを記録する。
4. Fan、Grid、List をそれぞれ明示し、フォルダを閉じて開き直しても選択が維持されるか確認する。
5. Automatic に戻し、項目をクリックして開く。Grid では矢印キーと Return または Space、Escape も確認する。
6. 標準 Dock に同じフォルダを追加し、Automatic を選ぶ。空、1件、8件、9件と下、左、右の配置を順に試し、選択形式と境界を記録する。
