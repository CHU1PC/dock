# アプリのウィンドウ一覧から選択して前面化する

GitHub issue #21 の実装になる。

## 仕様

- アプリの右クリックメニューに「ウィンドウを前面に表示」サブメニューを追加した。
- サブメニューを開いたときに、対象アプリの Accessibility API からウィンドウを列挙する。通常のウィンドウと最小化状態を表示する。
- 同じ名前のウィンドウには番号を付ける。最小化中のウィンドウには「最小化」と表示する。
- 選んだウィンドウの最小化を解除し、対象アプリを前面にして、AX の Raise アクションを送る。
- 一覧の取得は `ApplicationWindowProviding` の背後に置いた。単体テストでは偽物の provider を使う。
- Accessibility の許可がない場合は、システムの許可ダイアログを要求し、許可されなければサブメニューにシステム設定で Dock Studio を許可するよう表示する。既存の「開く」は通常メニューに残る。
- 起動していないアプリ、ウィンドウがないアプリ、取得に失敗した場合は、それぞれサブメニュー内に状態を表示する。

## 受け入れ条件との対応

| 条件 | 状況 |
| --- | --- |
| 対象アプリの開いているウィンドウを識別して一覧にする | 満たした。AX のウィンドウタイトルをサブメニューに出す。Fake provider を使うテストで結果の引き渡しを確認した |
| 通常・最小化・別 Space のウィンドウを選択できる範囲を確認する | 一部のみ。最小化状態を一覧に含め、選択時に解除する実装をした。別 Space の列挙と切替は VM で未確認 |
| 必要な権限の拒否時にも基本の起動操作を維持する | 満たした。拒否時は必要権限をサブメニューに表示し、通常メニューの「開く」を維持する |

## 検証

ホストでは指定のスクリプトで単体テストとビルドを実行した。GUI は起動していない。

| 項目 | 結果 |
| --- | --- |
| `swift test` | 260 件を実行し、失敗 0 件 |
| Release ビルド | 成功 |
| `build-for-testing` | 成功 |

### 未検証

- 専用 VM での実画面と、通常ウィンドウの前面化。
- 最小化ウィンドウの復元と前面化。
- 別 Space のウィンドウを一覧から選べるか、選択後に Space が切り替わるか。
- Accessibility 権限の許可と拒否時の実際のシステム表示。
- macOS 15 以降の OS 差分。

## 撮影の手順

撮影担当者は専用ヘッドレス macOS VM のゲストで確認する。ホストで Dock Studio を起動しない。

### 検証用データ

ゲストで `/Users/Shared/dockstudio-21` を作り、`profiles.json` に次の設定を置く。

```json
{
  "schemaVersion": 1,
  "activeProfileID": "00000000-0000-0000-0000-000000000001",
  "settings": { "mode": "custom", "position": "bottom", "iconSize": 64, "autoHide": false, "showRunningApps": false },
  "profiles": [
    {
      "id": "00000000-0000-0000-0000-000000000001",
      "name": "Window list demo",
      "items": [
        { "id": "00000000-0000-0000-0000-0000000000a1", "name": "Calculator", "kind": "application",
          "target": "file:///System/Applications/Calculator.app/" },
        { "id": "00000000-0000-0000-0000-0000000000a2", "name": "TextEdit", "kind": "application",
          "target": "file:///System/Applications/TextEdit.app/" }
      ]
    }
  ]
}
```

ゲストで Calculator と TextEdit を起動する。TextEdit で別々の文書のウィンドウを2つ開き、1つを最小化し、可能なら3つ目を別 Space に置く。最新のビルドをゲストに置き、次で起動する。

```
DOCKSTUDIO_DATA_DIR=/Users/Shared/dockstudio-21 /path/to/DockStudio.app/Contents/MacOS/DockStudio
```

### 操作と比較

1. Dock Studio の Custom Dock を表示し、TextEdit を右クリックして「ウィンドウを前面に表示」を開く。
2. 通常ウィンドウ、最小化ウィンドウ、別 Space のウィンドウが一覧に出るかを記録する。
3. 各ウィンドウを選び、選択後に対象の文書が前面になること、最小化が解除されること、別 Space に移動することを記録する。
4. 標準 macOS Dock でも TextEdit のアプリメニューを開き、同じウィンドウ状態について比較する。
5. 標準 Dock と Dock Studio で、一覧の項目数、ウィンドウ名、並び順、最小化表示、別 Space の項目の有無、選択後の動作を測る。
6. ゲストの「システム設定」から Dock Studio の Accessibility 許可を拒否または無効にして、サブメニューに権限の説明が出ることと、「開く」が使えることを確認する。撮影後は必要に応じて許可を戻す。
