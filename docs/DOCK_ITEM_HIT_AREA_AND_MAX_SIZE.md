# Dock 項目の当たり判定と最大サイズのパネル

Issue #197 に対応する。

## 仕様

- Dock 項目のクリック領域を、項目のフレーム全体に合わせる。アイコンの周囲にある既存の余白でも、アイコンと同じ操作を実行する。
- パネルと管理ウィンドウ内のプレビューは、同じ `DockBar` を使う。項目のボタンラベルに余白と実行中インジケーターを含め、表示位置と間隔を維持する。
- 画面下端の可視 Dock と画面の間隔を5ptに保ちながら、下側の透明余白を8ptから5ptに調整する。パネル枠の高さを3pt短くし、枠を画面外へ出さない。
- ヒット形状とパネル高さの計算は、画面描画から独立した純粋関数にする。

## 受け入れ条件との対応

| 条件 | 状況 | 根拠 |
| --- | --- | --- |
| アイコンサイズ16から128まで、クリック領域が各項目のフレーム全体と一致する | 満たした | `DockItemHitGeometryTests` がサイズ16から128を1pt刻みで、項目フレームとヒットフレームを比較した。単体テストのみ。パネルとプレビューは共有の `DockBar` を通る。 |
| 最大アイコンサイズで、パネルの高さと配置オフセットが画面高さ以内に収まる | 満たした | `PanelFrameGeometryTests.testMaximumIconSizePanelFitsWithinScreenHeight` が最大サイズ128、画面高900ptで高さと配置オフセットの合計を確認した。単体テストのみ。 |

## 検証

ホストでビルドと単体テストを実行した。アプリは起動していない。

| 項目 | 結果 |
| --- | --- |
| `swift test` | 423件、失敗0 |
| Release ビルド | 成功 |
| Debug の `build-for-testing` | 成功 |

### 未検証

- パネルとウィンドウ内プレビューを実画面で操作したときのクリック応答。
- Retina 表示、異なる解像度、複数ディスプレイ上のパネル枠。
- macOS の各対応バージョンでの SwiftUI ヒットテストの差異。

## 撮影の手順

実画面の撮影は行っていない。撮影する場合は専用のヘッドレス macOS VM で行い、ホストではアプリを起動しない。

### 検証用データ

ゲストに次の内容で `profiles.json` を用意し、`DOCKSTUDIO_DATA_DIR` にそのファイルを含むディレクトリを指定して Dock Studio を起動する。アイコンサイズは設定画面から16と128に切り替える。

```json
{
  "schemaVersion": 1,
  "activeProfileID": "00000000-0000-0000-0000-000000000001",
  "settings": { "mode": "custom", "position": "bottom", "iconSize": 16, "autoHide": false, "showRunningApps": false },
  "profiles": [
    {
      "id": "00000000-0000-0000-0000-000000000001",
      "name": "Hit area demo",
      "items": [
        { "id": "00000000-0000-0000-0000-0000000000a1", "name": "Calculator", "kind": "application", "target": "file:///System/Applications/Calculator.app/" },
        { "id": "00000000-0000-0000-0000-0000000000a2", "name": "Calendar", "kind": "application", "target": "file:///System/Applications/Calendar.app/" }
      ]
    }
  ]
}
```

起動例:

```
DOCKSTUDIO_DATA_DIR=/Users/Shared/dock-item-hit-area /path/to/DockStudio.app/Contents/MacOS/DockStudio
```

### 操作と期待する結果

1. パネルでアイコンの上下左右にある余白をクリックする。アイコン本体を押したときと同じアプリが開く。
2. 設定画面でアイコンサイズを128にする。パネル枠の下端が画面内に収まり、表示位置と Dock の間隔が保たれる。
3. 管理ウィンドウ内の「Custom Dock」プレビューでも、アイコンの周囲の余白をクリックする。同じアプリが開く。
