# 項目数に応じたアイコンの自動縮小

## 変更内容

外観の背景に「Apple Dock」を選んだ場合、Dock の表示可能な長さと項目数から、表示用アイコンサイズを計算する。項目が多くなっても、アイコンとその軸方向の余白を縮めて、画面内に収める。

保存する `settings.iconSize` は変更しない。項目数が減るか、画面の表示可能な長さが増えると、計算結果は設定サイズに戻る。ほかの背景を選んだ場合は、従来どおりスクロールする。

純粋関数 `DockIconAutoShrink.size` は、利用可能な長さ、固定長、縮小対象の長さからサイズを求める。サイズの上限は設定値、下限は既存のアイコンサイズ範囲の下限である16ポイントにした。16ポイントでも収まらないほど項目が多い場合は、下限を維持し、スクロールが残る。

## 仕様判断

- 標準互換表示は、背景が「Apple Dock」の場合とした。この背景が標準 Dock 風表示を選ぶ既存の設定になる。
- 項目、ゴミ箱、最小化ウインドウを縮小対象として数える。時計、集中タイマー、スペーサー、区切りは固定長に含める。
- アイコンが縮むときは、アプリ項目とゴミ箱の軸方向の余白も、設定サイズに対する表示サイズの比率で縮める。クリック可能なアイコンの最小サイズは16ポイントに保つ。
- 拡大を有効にした場合は、既存の拡大余白を計算に含める。名前表示やドラッグの画面内配置は、実画面では検証していない。

## 受け入れ条件との対応

| 条件 | 状況 | 根拠 |
|---|---|---|
| 標準互換モードで、利用可能な長さと項目数に応じて表示上のアイコンを縮小する | 一部のみ | 純粋関数の単体テストで、項目数に相当する縮小係数と利用可能長に応じた計算を確認した。設定サイズを上限にする処理も確認した。実画面とモード連携は未確認になる |
| 保存設定の `iconSize` を変更せず、項目数が減ったときに設定サイズへ戻す | 一部のみ | 純粋関数の単体テストで、収まる長さでは設定サイズを返すことを確認した。計算は設定を変更しないが、実画面での項目追加・削除は未確認になる |
| 最小クリック領域、名前表示、拡大、ドラッグを含め、画面内に収まることを確認する | 未確認 | 実画面を表示していない。16ポイントでのクリック、名前表示、拡大、ドラッグの位置は未確認になる |
| 下・左・右配置と異なる画面サイズで表示を確認し、画面を変更した PR に画面資料を添付する | 未確認 | 各配置と画面サイズでの確認、画面資料の撮影は行っていない |

### 未検証

- Apple Dock 背景で、実際の Dock が項目数に応じて縮小すること。
- 設定サイズが保存状態に保たれ、項目数が減った後に画面表示が戻ること。
- 最小クリック領域、名前表示、拡大、ドラッグが各画面内に収まること。
- 下・左・右の各配置と、異なる画面サイズでの表示。
- 16ポイントを下回るサイズが必要になる項目数での表示。下限に達した場合はスクロールが残る。
- macOS の画面端、複数ディスプレイ、実際の Dock との表示差。

## 撮影の手順

この手順は、後日、専用のヘッドレス macOS VM で画面を確認するときに使う。ホストでは Dock Studio を起動しない。

### 検証データ

ゲストで `/Users/Shared/dockstudio-141` を作り、そこに `profiles.json` を用意する。`DockDocument` の形式で、`schemaVersion` を1、`mode` を `custom`、`position` を `bottom`、`iconSize` を64にする。アクティブなプロファイルには、UUID の異なる60個の `application` 項目を入れ、各項目の `target` は Calculator のアプリ URL にする。

アプリの「設定」で、背景を「Apple Dock」にし、拡大を有効にする。設定データは `/Users/Shared/dockstudio-141` に保存する。

### 起動と操作

ゲストに置いた Release ビルドを次のように起動する。

```sh
DOCKSTUDIO_DATA_DIR=/Users/Shared/dockstudio-141 /path/to/DockStudio.app/Contents/MacOS/DockStudio
```

1. 60項目のプロファイルを表示し、下配置で、アイコンが設定サイズより縮んで全項目が見えるか確認する。
2. ポインタを各項目に移し、拡大したアイコンと名前が画面内に収まるか確認する。
3. 項目をドラッグし、並べ替えや Dock 外へのドラッグが操作できるか確認する。
4. 項目を減らし、アイコンが64ポイントへ戻るか確認する。設定値も64のままか確認する。
5. 左配置と右配置で同じ確認を行う。
6. VM の解像度を変え、下・左・右配置で項目が収まるか再確認する。
7. 標準 Dock 側でも同数の項目を用意し、サイズの縮小、設定サイズの保持、項目を減らしたときの復帰を比較する。

## 制約

画面での確認をしていないため、画面内に収まるかどうかは未確定になる。16ポイントの下限より多くの長さが必要な場合、スクロールが残る。
