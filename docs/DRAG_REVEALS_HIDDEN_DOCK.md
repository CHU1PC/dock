# 自動非表示中のドラッグによる Dock 表示

## 仕様

Custom Dock の自動非表示中に、ドラッグ中のポインタが Dock の反応領域に入ると、Dock を表示したままにする。反応領域は既存の `DockInteractionGeometry.reveal` が返す画面端の領域を使う。ポインタだけで表示する既存の動作と領域は変えない。

ドラッグが反応領域に触れた状態は、マウスボタンを離すまで保持する。項目を Dock にドロップすると、既存の `DockDropDelegate` が項目を追加する。ドラッグをキャンセルしたときも、ボタンを離した後は既存の自動非表示待ち時間に従って隠れる。

ドラッグ中の通知は、グローバルおよびローカルの左ボタンのドラッグイベントで検出する。左ボタンを離した通知で、ドラッグによる表示保持を解除する。

## 仕様判断

- ドラッグで表示を開始する位置は既存の反応領域と同じにする。左右と下の配置で共通の幾何計算を使う。
- ドラッグ中に反応領域を抜けても、ドロップまたはキャンセルまでは表示状態を保つ。ポインタだけの表示状態にはこの保持を適用しない。
- ドラッグ終了後は、現在の Dock の hover 判定と1秒の自動非表示待ち時間に戻す。
- 標準 Dock の反応領域と待ち時間は、この実装から推定しない。専用 VM の撮影時に実測し、この資料へ記録する。

## 受け入れ条件との対応

| 条件 | 状況 |
| --- | --- |
| 標準 Dock の自動非表示中にドラッグで表示する領域と待ち時間を専用 VM で確認し記録する | 未確認。末尾の撮影手順で測定する項目を定義した |
| Custom Dock をドラッグで表示し、ドロップで追加し、キャンセル後に隠す | 自動テストと実画面は未確認。状態遷移とドロップ処理は別々に自動テストした |
| 左右と下の配置で確認する | 自動テストでは反応領域の左右と下を確認した。VM での実画面は未確認 |

### 未検証

- macOS の専用 VM での実ドラッグ、ドロップ、キャンセルの画面と動画。
- 左、右、下の各配置での Custom Dock の実画面。
- 標準 Dock の反応領域の寸法と、端へ到達してから表示が始まるまでの待ち時間。
- ドラッグ中のグローバルイベントが、対象の macOS 15 以降の環境で配信されること。

## 撮影の手順

専用ヘッドレス macOS VM または検証用 Mac のゲストだけで実施する。ホストには Dock Studio や VM の画面を表示しない。標準 Dock の測定と Custom Dock の撮影は同じ画面解像度で行い、動画の時刻から時間を計測する。

### 検証データと起動

ゲストで `/Users/Shared/dockstudio-85` を作り、`drag-target.txt` を置く。次の `profiles.json` を同じ場所に保存する。

```json
{
  "schemaVersion": 1,
  "activeProfileID": "00000000-0000-0000-0000-000000000001",
  "settings": {
    "mode": "custom",
    "position": "bottom",
    "iconSize": 64,
    "autoHide": true,
    "showRunningApps": false
  },
  "profiles": [
    {
      "id": "00000000-0000-0000-0000-000000000001",
      "name": "Drag reveal demo",
      "items": [
        {
          "id": "00000000-0000-0000-0000-0000000000a1",
          "name": "Drag target",
          "kind": "file",
          "target": "file:///Users/Shared/dockstudio-85/drag-target.txt"
        }
      ]
    }
  ]
}
```

ゲストでアプリを起動する。

```
DOCKSTUDIO_DATA_DIR=/Users/Shared/dockstudio-85 /path/to/DockStudio.app/Contents/MacOS/DockStudio
```

### 標準 Dock の測定

1. macOS の Dock を自動的に隠す設定にする。画面解像度、Dock の配置、Dock のサイズを記録する。
2. Finder から `drag-target.txt` をドラッグし、Dock の配置側の画面端へゆっくり近づける。ドラッグ中のポインタ位置を少しずつ変え、Dock が最初に動き始める最も内側の位置を記録する。画面の原点と端からの距離も記録し、反応領域の範囲を示す。
3. 反応領域の外と内からそれぞれ3回ドラッグする。ポインタが境界を越えた時刻と Dock の表示が始まった時刻を動画のフレームから読み、各回の待ち時間を記録する。
4. 下、左、右の配置を切り替え、各配置で手順2と3を行う。各配置の領域と待ち時間を表にまとめ、測定中の動画を残す。

### Custom Dock の操作

1. Custom Dock の位置を下にし、自動非表示を有効にする。Finder で `drag-target.txt` をつかみ、Dock が隠れた状態から画面端の反応領域へドラッグする。
2. Dock が現れたら、そのまま項目上へ進み、Dock にドロップする。項目が追加されることを確認する。
3. 追加後、別のファイルを使って同じ手順で反応領域に入り、ドロップ前に Escape キーでキャンセルする。Dock が従来の待ち時間後に隠れることを確認する。
4. Dock の位置を左と右に変更し、下と同じくドロップとキャンセルを行う。
5. 画面の「設定」タブを選んだ状態で撮影する。ウィンドウ内のプレビュー Dock とデスクトップパネルを重ねない。

### 記録する測定結果

標準 Dock と Custom Dock で次を記録する。

- macOS のバージョン、画面解像度、画面座標の原点。
- 下、左、右それぞれの反応領域の端からの距離と範囲。
- 反応領域へ入ってから表示が始まるまでの時間。各配置で3回測り、個々の値と中央値を記録する。
- 表示が始まった後、ドラッグを続けたときに Dock が開いたままになるか。
- ドロップ後の追加結果と、キャンセル後に隠れるまでの時間。
