# フォルダ内容ポップオーバーのキーボードフォーカス

## 変更内容

フォルダ内容ポップオーバーを開いた直後に、表示先ウィンドウをキーウィンドウにし、ポップオーバーのコンテナへキーボードフォーカスを要求する。パネルがキーウィンドウのままでも、パネルのキー処理より先に Escape と矢印キーをポップオーバーへ渡す。Grid 表示では読み込み後に先頭項目へフォーカスを移し、矢印キーで項目を移動する。

## 仕様判断

- ポップオーバーのウィンドウが SwiftUI の表示後に利用可能になってから、メインスレッド上でキーウィンドウにする。
- Escape を受けるためのコンテナフォーカスを先に要求し、Grid の項目が読み込まれた後は先頭項目を選ぶ。キーウィンドウが切り替わらない場合は、パネルのキー処理がアクティブなポップオーバーへ先にキーを渡す。
- 初期 Grid 項目の選択と、ポップオーバーが開いている間のキー振り分けは純粋関数に分けて単体テストする。
- App Exposé は既存の Custom Dock メニュー項目が標準 Dock の Accessibility メニューを操作しているため、実装を重複させない。

## 撮影の手順

今回の作業では、加藤さんの指示により実画面の撮影を行っていない。後日確認する場合は専用のヘッドレス macOS VM または検証用 Mac のゲストを使い、ホストではアプリを表示しない。

ゲストに Grid 表示のフォルダと複数の項目を持つ `profiles.json` を用意する。Release 成果物をゲストで起動し、Custom Dock のパネルと管理画面内プレビューの両方でフォルダを開く。開いた直後に余白をクリックせず Escape を押して閉じ、開き直して矢印キーでフォーカスを移動する。

撮影する場合は、Grid のポップオーバーと、Escape および矢印キーの操作が分かる動画を残す。標準 Dock の「Show All Windows」操作は、この確認手順には含めない。
