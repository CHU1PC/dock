# バックグラウンド実行の設定案内

## 仕様

標準 Dock 用の Dock Studio メニューに「バックグラウンド実行を設定…」を追加する。選ぶと `SMAppService.openSystemSettingsLoginItems()` を呼び、システム設定のログイン項目画面を開く。案内先は「システム設定 > 一般 > ログイン項目と機能拡張 > バックグラウンドでのアプリのアクティビティ」と表示する。

案内は macOS の設定を開くだけで、DockStudio が他のアプリやヘルパーを終了させることはない。「Stop Running in Background」は通常終了や強制終了とは異なる設定であり、変更すると同期や自動更新が止まる場合があるとメニューに記載する。停止対象の詳しい範囲と、macOS 27 での実際の操作条件は、関連調査 `docs/research/OS_FEATURES.md` の #67、#70 と同じく未確認として扱う。

## 撮影の手順

### 検証用データと起動

ゲストの `/Users/Shared/dockstudio-134` に `profiles.json` を置く。既存プロファイルを使う場合はそのパスを `DOCKSTUDIO_DATA_DIR` に指定する。撮影時は Release ビルドの `DockStudio.app` をゲストに置き、次のように起動する。

```sh
DOCKSTUDIO_DATA_DIR=/Users/Shared/dockstudio-134 /path/to/DockStudio.app/Contents/MacOS/DockStudio --native-dock-tile
```

### 操作

1. Dock Studio のアイコンが標準 Dock に表示されたことを確認する。
2. アイコンを Control キーを押しながらクリックし、Dock Studio のメニューを表示する。
3. 「バックグラウンド実行を設定…」と、遷移先および同期・更新への注意書きを撮影する。
4. 項目を選び、システム設定のログイン項目画面が開くことを確認する。macOS 27 では「バックグラウンドでのアプリのアクティビティ」の項目が見える位置まで表示する。
5. Dock Studio の案内を使っても、他のアプリやヘルパーが終了しないことを確認する。

### 期待する結果

メニューに設定画面への案内と注意書きがあり、選択するとログイン項目の設定画面が開く。Dock Studio は他のアプリやヘルパーを終了させない。
