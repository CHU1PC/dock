# GPUI への UI 移行

## 決定と理由

2026-10-16 に、Custom Dock、設定画面、プロファイル編集画面を GPUI に移す方針が承認された。背景とアイコンを自由に編集しながら、現在使っている Mac の Apple Dock に近い外観と操作感を目指す。

以前は SwiftUI と AppKit で全画面を実装していた。今後は UI を Rust と GPUI で実装する。保存形式と検証済みの macOS 連携は Swift のヘルパーに残す。GPU 描画を使うことだけでは軽量化を保証できないため、性能は実測する。

## 対象

- Custom Dock の描画を GPUI に移す。
- 設定画面とプロファイル編集画面を GPUI に移す。
- Apple Dock に近い余白、角丸、背景、輪郭、影を使う。
- ホバー時の拡大、名前の表示、起動中の点、自動非表示の動きを追加する。
- Dock の背景を、システムのぼかし、単色、画像、完全透明から選べるようにする。
- 背景の色、ぼかし、透明度を調整できるようにする。
- アイコンを、通常、白黒、透けた単色のガラス調から選べるようにする。
- プロファイルの編集、保存、下書き復元、インポートとエクスポート、ファイルとアプリの選択を引き継ぐ。

デスクトップの壁紙は変更しない。WSL の CPU と GPU のデータ取得は、今回の UI 移行には含めない。

## 構成

| 場所 | 役割 |
| --- | --- |
| gpui/src | UI、ホバーと表示の状態、テーマ、タイマーを担当する |
| gpui/native | Swift の保存処理と macOS API を、構造化された要求から呼び出す |
| gpui/scripts | ビルド、起動、検証、画面記録を担当する |
| DockStudio | 移行中の既存実装と、共有するモデルとサービスを保持する |

GPUI は crates.io の 0.2.2 に固定する。Cargo.lock を含め、最新の Zed の内部 API への依存を避ける。既存 profiles.json の形式と UUID を引き継ぐ。外観設定は別ファイルに保存し、旧アプリによる読み込みを妨げない。

## 実装順序と確認条件

1. GPUI のビルドとウィンドウ制御を確認する。通常の検証では画面を表示しない。
2. 既存の保存処理を呼び出すヘルパーを作る。読み込み失敗時の保護と下書き復元を維持する。
3. Dock、設定、プロファイル編集を移す。実際の操作でデータが保存されることを確認する。
4. 外観設定、ホバー拡大、起動中の点、自動非表示を実装する。
5. 自動テスト、ビルド、描画の記録、Sonnet のコードレビューを実施する。レビュー指摘は全件対応する。
6. PR 本文に変更した画面の画像と、動きが分かる動画を載せる。実機で未確認の項目を明記する。

## 進捗

Dock、設定画面、プロファイル編集を GPUI で実装した。既存形式の保存、下書き復元、読み取り専用の保護、インポートとエクスポートをヘルパーで引き継いだ。背景とアイコン加工、ホバー拡大、起動中の点、自動非表示を追加した。管理画面を閉じても常駐し、メニューバーと右クリックから操作できる構成にした。

Rust の 17 テストと、既存 Swift の 44 テストが通っている。Sonnet のレビューを 1 回実行し、[レビュー原文](../gpui/REVIEW.md)と[対応表](../gpui/REVIEW_FIXES.md)を残した。既存の SwiftUI 版は、比較と回帰確認のため保持している。

## 既知の退行と未検証事項

GPUI 0.2.2 は AX ツリーを提供しないため、GPUI 画面を VoiceOver で操作できない。キーボードの Tab 移動と、Enter または Space でのボタン操作は追加した。VoiceOver 対応が完了するまで、全面移行の完了とは扱わない。

実デスクトップでの click-through、Spaces、全画面、ディスプレイの抜き差し、標準ダイアログとの往復、常駐とメニューの操作は未検証である。画面情報は 1 秒ごとの更新であり、切断直後に最大 1 秒の遅れがある。macOS 15、Intel Mac、ホバー時の実性能も確認する必要がある。

画面の記録では実際の GPUI を画面外に描画する。ホバーと自動非表示は状態を制御して記録し、実マウス操作の録画とは区別する。

## 撮影の状態

2026-10-17 に画面ロック解除後の再撮影を完了した。最新の管理画面 3 ページ、外観設定の下部、通常、白黒、ガラス調、透明の Dock を取得した。ホバーと自動非表示の状態変化を 60 フレームで記録し、5 秒の動画にした。NSView と GPUI の viewport の検査も通った。画像と動画は [docs/media/gpui](media/gpui) に保存した。

前日の撮影失敗は、Mac の画面ロックが原因だった。以前のビルドでも同じ失敗を再現し、CGSessionCopyCurrentDictionary の CGSSessionScreenIsLocked が 1 であることを確認した。撮影コマンドには、ロック状態を検出して停止する処理を追加した。
