# Dock のアイコンサイズの範囲

## 標準 Dock の範囲の確認結果

Apple の Dock 設定仕様（[Dock payload](https://developer.apple.com/documentation/devicemanagement/dock)）では、tile size の設定範囲は16〜128になる。

標準 Dock の「システム設定 > デスクトップと Dock」にあるサイズスライダーの実際の範囲は、この作業では確認できていない。専用ヘッドレス VM（macOS 26.6.2）が他のエージェントに約30分間占有され、ロックを取得できなかったためである。そのため、アプリの範囲は Apple の仕様値に合わせた。UI の範囲と差があった場合は、この文書を更新する。

## 変更内容

`DockSettings.iconSizeRange` を16〜128として定義し、次の3か所で共通に使う。

| 箇所 | 変更前 | 変更後 |
| --- | --- | --- |
| 保存データの検証（`DockDocument.validate`） | 40〜76 | 16〜128 |
| 設定画面のスライダー（刻みは2のまま） | 40〜76 | 16〜128 |
| アイコンのスタイル変換の解像度（`DockIconRenderer`） | 76を基準 | 上限の128を基準 |

古い保存データとバックアップは、40〜76の値も、`revealAnimationDuration` が欠けた形式もそのまま読み込める。範囲外の値と非有限値は従来どおり拒否する。`iconSize` 自体は従来から必須項目で、この変更でも変えていない。

## 検証

2026-10-17 に、ホストで以下を確認した。

| 項目 | 結果 |
| --- | --- |
| Release ビルド | 成功した |
| `swift test` | 87件すべて成功した（新規5件） |
| 16、40、76、128 | 保存、再読込、バックアップ復元で保持された |
| 15.99、128.01、0、負数、無限大、NaN | 保存を置き換えず、エンコードも失敗した |
| 40〜76の値と、`revealAnimationDuration` が欠けたデータ | 値を保ったまま読み込めた |
| スライダーの一時値 | 16と128を一時値に設定し、確定で保存された |

## 未検証

GUI の確認は、VM を使えなかったため行っていない。次の項目は未検証である。

- 標準 Dock のサイズスライダーの実際の最小値と最大値
- 設定画面のスライダーの両端での表示
- 最小（16）と最大（128）での Dock の収まりとクリック領域
- 拡大率の最大（2倍）との組合せ
- 左右配置、Retina、多数の項目
- macOS 15〜25 でのスライダーの範囲の差
- 128 での描画の解像度と性能
