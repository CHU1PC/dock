# Dock の区切り線をドラッグしてサイズを変える

GitHub issue #50 の実装になる。

## 仕様

Custom Dock の項目とゴミ箱の間にある区切り線をドラッグすると、アイコンサイズを変更する。線の周囲に操作しやすいヒット領域を設け、ドラッグ中はサイズ変更カーソルを表示する。

- 下配置では上下にドラッグし、上へ動かすと大きく、下へ動かすと小さくなる。
- 左配置では左右にドラッグし、右へ動かすと大きく、左へ動かすと小さくなる。
- 右配置では左右にドラッグし、左へ動かすと大きく、右へ動かすと小さくなる。
- 移動距離とサイズの変化量は1対1にする。DockSettings.iconSizeRange の範囲（16から128）を超えない。
- 並べ替え対象のアイコンではなく区切り線にだけドラッグ操作を付ける。既存の DockStore の編集処理を通し、設定画面、保存値、再起動後の値に同じサイズを使う。
- 変換処理は DockIconSizeResize.size に分け、方向、使用軸、上下限を単体テストで確認する。

## 撮影の手順

撮影は専用ヘッドレス macOS VM または検証用 Mac のゲストで行う。ホストにはアプリを表示しない。Release ビルドの `DockStudio.app` をゲストへ配置し、検証データには `/Users/Shared/dockstudio-50/profiles.json` を使う。初回起動で作られる標準プロファイルを使い、設定画面で表示モードを Custom Dock に、配置を下にする。撮影後、配置を左、右にも切り替える。

起動時は、ゲストで次を実行する。

```sh
mkdir -p /Users/Shared/dockstudio-50
DOCKSTUDIO_DATA_DIR=/Users/Shared/dockstudio-50 /path/to/DockStudio.app/Contents/MacOS/DockStudio
```

1. 下配置で Custom Dock を表示する。項目とゴミ箱の間にある区切り線へポインタを置き、サイズ変更カーソルと線の位置を確認する。
2. 区切り線を上へドラッグし、アイコンが大きくなることを確認する。設定画面のスライダーが同じ値になり、Dock Studio を再起動しても値が保持されることを確認する。
3. 区切り線を下へドラッグし、アイコンが小さくなることを確認する。最小サイズと最大サイズでさらにドラッグし、範囲外にならないことを確認する。
4. Dock のアイコンをドラッグし、区切り線のサイズ変更と項目の並べ替えが混同されないことを確認する。
5. 配置を左にし、区切り線を左右へドラッグする。右方向で大きく、左方向で小さくなることを確認する。
6. 配置を右にし、区切り線を左右へドラッグする。左方向で大きく、右方向で小さくなることを確認する。
7. 標準 macOS Dock の区切り線も同じ配置と方向で操作し、アイコンサイズの変化方向と操作距離を比較する。
