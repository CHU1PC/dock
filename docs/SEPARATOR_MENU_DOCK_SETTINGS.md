# 区切り線から Dock 設定を変更する

## 変更内容

Custom Dock のゴミ箱前にある区切り線を右クリックすると、配置、拡大、自動非表示を変更できます。現在の値にはチェックマークを表示します。各項目は選択直後に既存の設定保存処理を使って保存します。

メニューの「Dock 設定を開く…」を選ぶと管理画面を開き、「設定」タブを表示します。位置と自動非表示は `profiles.json` の `DockSettings` に保存し、拡大は既存の外観設定ファイルに保存します。

## 仕様の決定

- 配置は左、下、右から選び、現在の値をチェックマークで示す。
- 拡大と自動非表示は、現在値をチェックマークで示す項目として切り替える。
- 保存先を既存の設定モデルと保存処理に合わせる。複数の設定をまとめて変更しない。
- 読み取り専用のプロファイルまたは外観設定では、対応するメニュー項目を無効にする。
- コンテキストメニューは SwiftUI の標準メニュー操作に従い、キーボードからも選べる。
- 「Dock 設定を開く…」を選ぶと、管理画面の「設定」タブを表示する。

## 撮影の手順

撮影は専用のヘッドレス macOS VM または検証用 Mac のゲストで行う。ホストには検証画面を表示しない。

### 検証用データ

ゲストで `/Users/Shared/dockstudio-51` を作り、次の内容を `profiles.json` に保存する。

```json
{
  "schemaVersion": 1,
  "activeProfileID": "00000000-0000-0000-0000-000000000051",
  "settings": {
    "mode": "custom",
    "position": "bottom",
    "iconSize": 64,
    "autoHide": false,
    "showRunningApps": false
  },
  "profiles": [
    {
      "id": "00000000-0000-0000-0000-000000000051",
      "name": "Separator menu demo",
      "items": [
        {
          "id": "00000000-0000-0000-0000-000000000052",
          "name": "Finder",
          "kind": "application",
          "target": "file:///System/Library/CoreServices/Finder.app/"
        },
        {
          "id": "00000000-0000-0000-0000-000000000053",
          "name": "Calculator",
          "kind": "application",
          "target": "file:///System/Applications/Calculator.app/"
        }
      ]
    }
  ]
}
```

ゲストに配置したアプリを次のように起動する。

```sh
DOCKSTUDIO_DATA_DIR=/Users/Shared/dockstudio-51 /Applications/DockStudio.app/Contents/MacOS/DockStudio
```

### 操作と期待する結果

1. Custom Dock を表示し、区切り線を右クリックする。配置のサブメニューで「下」にチェックが付いていることを確認する。
2. 「左」を選ぶ。Dock が左側へ移動し、メニューを開き直すと「左」にチェックが付くことを確認する。
3. 「拡大」を選び、項目にポインタを重ねる。アイコンが拡大することを確認する。メニューを開き直し、拡大にチェックがあることを確認する。
4. 「使用していないときに隠す」を選ぶ。ポインタを Dock の外へ移し、Dock が隠れることを確認する。画面端へ戻すと現れることを確認する。
5. 区切り線のメニューで「Dock 設定を開く…」を選ぶ。管理画面が開き、「設定」タブと Dock 設定が表示されることを確認する。
6. 位置、拡大、自動非表示を設定画面から変更し、区切り線のメニューを開き直す。両方の入口で同じ状態が示されることを確認する。
7. キーボードで区切り線のコンテキストメニューを開き、矢印キーと Return で項目を選べることを確認する。
8. 標準 macOS Dock の区切り線を Control クリックし、対応する設定メニューを開く。表示と操作を比較する。

### 標準 Dock との比較で記録する項目

- メニューを開く操作、区切り線上のヒット領域、メニューが出る位置。
- 配置、拡大、自動非表示の項目名と、現在値を示す選択マーク。
- 設定変更後の反映までの時間と、設定画面を開いた後の値の一致。
- 拡大時の通常アイコンと最大アイコンの見た目の差。比較のため、同じ画面解像度と同程度のアイコンサイズで撮る。
- 自動非表示時に隠れるまでの時間、画面端にポインタを置いてから再表示するまでの時間。
- 位置を左、下、右へ変更した後の Dock の端からの距離と配置。
- キーボードだけでメニューを開き、設定を変更できるか。
