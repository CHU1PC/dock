# Apple Dock の背景プリセット

## 動作

背景の選択肢に「Apple Dock」を追加した。既存のシステム素材、単色、画像、完全透明は、そのまま選べる。既存の設定と、新規作成時の既定値も変更しない。

macOS 26 では、SwiftUI の `glassEffect(.clear)` を背景に使う。独自の不透明度、色、輪郭、影を追加しない。ネイティブのガラス効果の外側をクリップせず、角丸と縁の描画を素材に任せる。macOS 15〜25 では、既存の AppKit の HUD 素材にフォールバックする。

「Apple Dock」は固定プリセットなので、不透明度とぼかしの操作を隠す。カスタム背景の値は保存したままにし、別の背景へ戻したときに使う。アプリアイコンの外観は独立して選べる。

Apple が公開している[カスタムビュー向けの Liquid Glass](https://developer.apple.com/documentation/swiftui/applying-liquid-glass-to-custom-views)を使った近似になる。標準 Dock の非公開の素材を取得したり、その設定を書き換えたりする機能ではない。

## 検証

2026-10-17 に、以下を確認した。

- Release ビルドが成功した。
- 自動テスト75件が成功した。背景の保存と再読込、カスタム背景へ戻したときの色、不透明度、ぼかしの保持を含む。
- macOS 26.6.2、4 CPU、6 GiB、1600×1000の専用 VM 内で、選択と表示を確認した。
- 「システム素材」のぼかしを無効にしてから「Apple Dock」を選んでも、プリセットの素材は表示された。保存した blur は false のままだった。
- アプリを再起動した後も、Apple Dock の選択とカスタム値が復元された。
- 設定画面の幅900でも、背景の5つの選択肢が省略されずに表示された。
- 管理画面を閉じた後のデスクトップ用パネルを撮影した。

VM 内の標準 Apple Dock も、比較用に一時表示して撮影した。撮影後は、ゲストの自動非表示設定を元に戻した。ホストの Dock の設定と表示は変更していない。検証用アプリ、VM のウィンドウ、VNC ビューアーは、ホストに表示していない。

変更前後の管理画面、外観設定、最小幅での設定、デスクトップ用パネル、比較用の標準 Dock は、[画面の記録](media/apple-dock-background/)に保存した。変更前は main の c94bef4 を基準にした。

変更後の画像と標準 Dock の参照画像は、位置修正後の4f540a2のビルドで撮り直した。PR 本文には最新の画像を掲載し、位置修正前の「変更後」画像は掲載しない。

## レビューへの対応

Sonnet のレビューを1回実施した。確定した不具合の指摘はなく、判定は APPROVED だった。実行時の懸念には、以下のように対応した。修正後の再レビューは行っていない。

| 懸念 | 確認と対応 |
| --- | --- |
| ガラスの縁と影が外側のクリップで欠ける可能性がある | VM で確認した初期案は平坦に見えたため、標準プリセットを SwiftUI のガラス効果に変更した。外側のクリップと独自の影を適用せず、明暗が混在する壁紙で描画を確認した |
| 背景の選択肢が狭い画面で溢れる可能性がある | 幅900の設定画面を撮影し、5つのラベルと説明文が表示されることを確認した |
| 背景を分岐する既存コードに取りこぼしがある可能性がある | background の比較と switch を検索した。必要な分岐を追加し、ビルドとテストを確認した |
| contentView がない NSGlassEffectView の描画を確認する必要がある | 標準プリセットの macOS 26 の描画は、SwiftUI のガラス効果に変更した。既存のカスタム背景には変更を加えていない |

## 残る確認

macOS 15〜25 のフォールバックの実表示と、実機 GPU での描画品質は未確認になる。VM の画像を、標準 Dock と画素単位で同一であることの証拠や、実機性能の測定としては扱わない。
