## 共通の条件

- 実画面の確認は、Tart のヘッドレス VM（macOS 26.6.2、1600×1000）の 1 環境だけで行った。
- VNC の画面は数秒遅れるため、画像とログが食い違う場合はログと AX の値を正とした。
- 標準 Dock との比較、複数ディスプレイ、macOS 15 と 27、別の Space と Mission Control などは、多くの項目で「確認できず」になっている。

## 文書に書かれた限界（確認できず）

- A: 20 項目でのスクロールとドラッグ中の自動スクロールは確認できなかった。デスクトップ用パネルでのドラッグは行っていない。
- B: Accessibility の許可を付ける操作は安全装置に止められたため、「許可あり」側は確認できていない。表示中に項目が削除された場合、1 秒前に離れて取り消す操作、操作補助設定を無効にした場合も確認できなかった。#128 と #129 は全体が確認できなかった。標準 Dock との比較は省略した。
- C: 設定画面でのショートカットの変更、Dock が隠れる場合の拡大切替、複数ディスプレイ、Space と Mission Control、VoiceOver と Accessibility が要る操作は確認できなかった。標準 Dock との比較は省略した。
- D: macOS 15 と 27、Handoff の相手機器、複数ディスプレイは環境に無いため確認できなかった。Accessibility の許可なしの起動は、VM の仕組み上、未実施である。調査 issue の多くは「確認できず（省略）」または「一部のみ」である。
- 画像が無い項目や、画像だけでは判断できない項目は、各文書がその旨を記している（例として、D の 60 項目での縮小は描画の確認が一部のみ）。
