# #173 実画面確認 担当 A の記録

確認対象は main の `8849979` を Release でビルドしたアプリで、実行ファイルの SHA-256 はホストとゲストで一致した（`1d7c9852876b0a3d0d6544bec1e5854f0b9fbbf83c00486ddac46fe73c0bd57c`）。

確認環境は Tart ヘッドレス VM（macOS 26.6.2、1600×1000）になる。入力はゲスト内の CGEvent（`guest-drag`、`guest-realmods` など）と VNC を使い、画面は VNC で撮った。管理ウィンドウの「Custom Dock」タブにあるプレビュー Dock を操作対象にしている。

注意点がある。VNC の画面と Dock Studio の表示は、状態が変わってから数秒遅れて更新される。画像とログが食い違う場合は、ログ（`profiles.json`、`recent-apps.json`、Accessibility の項目一覧）を正にした。
