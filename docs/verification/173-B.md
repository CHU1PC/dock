# #173 実画面確認 担当 B の結果

対象は main の `8849979` の Release ビルドになる。実行ファイルの SHA-256 は、ホストとゲストの両方で `1d7c9852876b0a3d0d6544bec1e5854f0b9fbbf83c00486ddac46fe73c0bd57c` と一致した。確認は専用ヘッドレス VM（macOS 26.6.2、画面 1600×1000）で行い、ゲストの `/Users/Shared/dockstudio-B` に fixture を作って `DOCKSTUDIO_DATA_DIR` で起動した。画像は `docs/media/verification-173/B/` にある。

## 共通の注意

- ゲストの Dock Studio には Accessibility の許可が無い。許可を付ける操作（TCC データベースの書き換え、システム設定の起動）は、実行環境の安全装置に止められたので行っていない。このため、Accessibility が要る条件の「許可あり」側は確認できていない。
- Automation（Dock Studio から Finder）は、最初は拒否の状態だった。拒否の状態を先に確認し、`tccutil reset AppleEvents app.dockstudio.preview` の後に、同意ダイアログで Allow を押して許可の状態も確認した（ゲストのみの変更）。
- VNC のキー入力とクリックは遅れる。ログと AX の値を正とし、画像だけを根拠にしない。
- 標準 Dock との比較は、指示により「確認できず（省略）」とする。
