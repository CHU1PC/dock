# 開発状況

## 現在の目標

採用した Custom Dock、設定、プロファイル編集の3画面を基に、保存と画面間の反映、独立した Dock の操作を実装する。

## 方針と理由

SwiftUI の画面は共通の `DockStore` を参照する。編集用の下書きと保存済みのプロファイルを分けることで、画面移動で編集を失う問題を防ぐ。

設定はバージョン付き JSON に保存する。読み込みに失敗したファイルは保護し、書き込みに失敗した変更を保存済みとして扱わない。

Custom Dock は AppKit の独立したパネルで表示する。Apple Dock への配置の適用は、読み取りと別の工程で検証する。

## 検証

保存、編集、読み込み失敗、書き込み失敗、プロファイルの追加、タイマーの経過時間を確認した。レビュー修正の回帰テストを加えた44件がすべて通った。実画面の検証では、専用の一時保存先を使った。

管理画面から変更した名前の保存と、アプリ再起動後の復元を確認した。独立した Dock の右端配置、自動非表示、ポインタを重ねたときの再表示も確認した。[画面と検証記録](VERIFICATION.md)に証拠を残した。

利用者の作業を妨げたため、実行中の管理画面と Custom Dock を終了した。以後の修正確認は、Swift Package のテストとビルドを使い、画面にアプリを表示せずに行った。

Sonnet のコードレビューを1回実施し、[指摘10件を原文で保存した](FOUNDATION_REVIEW.md)。共有された作業規則に従い、全10件の修正を承認され、[修正結果](REVIEW_FIXES.md)に対応を記録した。

Apple Dock の読み取りは macOS 26.5.2 で11項目を取得できた。macOS 15 の実機、Intel Mac、複数画面、フルスクリーンでの検証は残っている。
