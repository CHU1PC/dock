# Dock のライト・ダーク追従

## 仕様

設定画面の「外観」に「Dock の明るさ」を追加した。選択肢は「システムに合わせる」「ライト」「ダーク」の3つになる。既定値は「システムに合わせる」で、macOS のライトとダークの切り替え（自動切替を含む）に Custom Dock が従う。従来は Dock が常にダークで描画されていた。

値は `DockAppearance.colorMode` として、外観設定（appearance.json）に保存する。保存データにこの項目がない場合は「システムに合わせる」で読み込む。以前の保存データは、そのまま読み込める。未知の値は、他の外観項目と同じく読み込みを拒否し、元のファイルを保護する。

デスクトップ用パネルは `NSPanel.appearance` に設定を反映する。「システムに合わせる」は nil なので、macOS の外観がそのまま届く。管理画面内の Dock プレビューは、環境の colorScheme で上書きする。管理画面は従来どおりダーク固定で、今回は変更していない。

ライトで見えにくくなる、白に固定していた描画を `.primary` と `.secondary` に変えた。対象は、区切り線、時計と集中タイマーのタイル、代替アイコン、空のプロファイルの案内文になる。

ガラス調アイコンは、白いグリフと不透明度の変化でできた画像を作る。ライトでは白いグリフが明るいガラスに埋もれたため、ライトのときだけ黒いグリフで作る。画像のキャッシュには、ガラス調のときだけ明暗の別をキーに含める。白黒と通常のアイコンは、明暗で描き分けない。

利用者が選んだ単色と画像の値は、明暗の設定で書き換えない。背景の描画も変えていない。

## 検証

2026-10-17 に、以下を確認した。

| 項目 | 結果 |
| --- | --- |
| Release ビルド | 成功した |
| `swift test` | 97件すべて成功した |
| `xcodebuild build-for-testing` | 成功した（`xcodebuild test` は、ホストの画面にアプリが出るため実行していない） |
| 古い保存データ | `colorMode` がなくても「システムに合わせる」で読み込め、単色の値も変わらなかった |
| 保存と再読込 | 3つの値が往復した。不正な値は読み込みを拒否した |
| 単色と画像のパス | 明暗を切り替えて保存しても変わらなかった |
| ガラス調のグリフ | 黒のグリフは RGB が0で、不透明度は白のグリフと一致した |

GUI は macOS 26.6.2、1600×1000の専用ヘッドレス VM 内で確認した。ホストのデスクトップには、アプリや VM の画面を表示していない。ゲストは、開始時にライトだった。

- 外観が Apple Dock、アイコンがガラス調の設定で、ゲストのシステム外観をライトとダークに切り替えた。デスクトップの Dock が、操作なしで追従した。
- ダークのシステムで「ライト」を選ぶと、Dock がライトの描画になった。「システムに合わせる」に戻すと、システムに従った。
- ガラス調で、ライトのアイコンが見えにくい問題を確認した。修正前のライトでは、Finder の顔や Downloads の絵が背景にほぼ溶けた。修正後は黒のグリフで判別できる。ダークは、修正の前後で変わらない。
- 白黒のアイコンは、ライトとダークの両方で判別できた。
- システム外観を、ライト、ダーク、ライトの順に切り替える動画を撮影した。

画像と動画は[画面と動画](media/dock-follow-appearance/)に保存した。

| ファイル | 内容 |
| --- | --- |
| `settings-system-light.png` | ライトのシステムでの「外観」設定 |
| `settings-system-dark.png` | ダークのシステムでの「外観」設定 |
| `settings-explicit-light-on-dark-system.png` | ダークのシステムで「ライト」を選んだ画面 |
| `desktop-light-glass.png`、`desktop-dark-glass.png` | ライトとダークのデスクトップ全体（ガラス調） |
| `dock-light-glass.png`、`dock-dark-glass.png` | 修正後の Dock の拡大（ガラス調） |
| `dock-light-mono.png`、`dock-dark-mono.png` | 白黒のアイコン |
| `before-fix-dock-light-glass.png`、`before-fix-dock-dark-glass.png` | 修正前の Dock の拡大（比較用） |
| `appearance-toggle.mp4` | ライト、ダーク、ライトの切り替え（約14秒、倍速ではない） |

動画は、撮影時刻の間隔を維持して15fpsに変換した。VM の撮影であり、実機の描画や所要時間の測定ではない。

撮影時は、管理画面をデスクトップの外へ移動した。設定画面の画像では、Dock のパネルが画面の下端で管理画面に重なっている。

## 未検証

- 透明度低減: ゲストで `defaults write com.apple.universalaccess reduceTransparency` を実行したが、Dock の見た目は変わらず、反映を確認できなかった。設定は撮影後に削除した。アプリは `accessibilityReduceTransparency` を参照する既存の処理（macOS 15〜25 のガラス調の代替）を変えていない。
- macOS 15〜25 のフォールバック（`NSVisualEffectView` の素材）の明暗。
- 単色、画像、システム素材の背景をライトで表示したときの見え方。コードの上で値を保持することだけを確認した。濃い単色をライトで選ぶと、前景は黒になる。読みやすさは未確認になる。
- 縦置き（左右）の配置、自動非表示との組合せ、複数ディスプレイ。
- 自動切替（日没でのシステムの切り替え）。システムの設定を手で切り替えて確認した。
- クリックのポップアップ（時計）の明暗。
- 実機の描画品質。

管理画面と設定画面は従来どおりダーク固定で、システムの外観には追従しない。追従させる場合は、別の変更として扱う。
