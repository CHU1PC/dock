# OS のアプリ一覧を Dock から開く

## 変更内容

プロファイル編集の「項目を追加」に、現在の macOS で利用できる標準アプリ一覧への項目を追加した。macOS 15 では `com.apple.launchpad.launcher` を Launchpad として、macOS 26 以降では `com.apple.apps.launcher` を「アプリ一覧」として解決する。バンドル ID からアプリの URL を解決できる場合だけ追加メニューに出し、プロファイルにはファイルパスを保存しない。

既存のプロファイルを別バージョンの macOS で開いた場合も、その OS の標準入口を再解決する。解決できない場合は Dock とプロファイル編集の一覧から隠し、開く処理でも利用可能な入口を再確認する。Spotlight や検索 UI は実装していない。

## 仕様上の判断

- macOS 15 は調査資料にあった未確認の候補 ID を使うが、実行時に解決できなければ項目を出さない。
- macOS 16 から 25 は既知の入口がないため項目を出さない。
- macOS 26 以降は `Apps.app` のバンドル ID を使う。OS 更新後にパスが変わっても、固定パスを保存しない。
- macOS 15 の候補 ID と、26 の `Apps.app` が実際に一覧を表示するかは、実機または VM で確認できていない。

## 受け入れ条件との対応

| 条件 | 状況 | 根拠 |
|---|---|---|
| macOS 15 の Launchpad と macOS 26 以降のアプリ一覧への入口を OS ごとに確認する | 未確認 | 単体テストは候補 ID と解決条件を確認する。OS 上の入口と実際の表示は未検証 |
| DockStudio にアプリ一覧を開く専用項目を追加する | 満たした | 単体テストのみ。利用可能な入口を専用項目として生成し、追加メニューから選べる |
| 利用可能な OS 標準入口だけを表示し、存在しないバンドル ID やパスを残さない | 満たした | 単体テストのみ。解決できない場合は項目を生成せず、生成項目の target は nil |
| Spotlight や OS のアプリ検索画面を複製しない | 満たした | 単体テストのみ。OS の標準アプリを開く項目だけを生成する |
| 対応 OS で実際の一覧表示を検証し、変更画面を記録する | 未確認 | 実画面の撮影と OS 統合確認は行っていない |

## 自動テスト結果

ホストでは GUI を起動せず、ビルドと単体テストを実行した。

| 確認 | 結果 |
|---|---|
| `swift test` | 349 件成功、失敗 0 |
| Release ビルド | `BUILD SUCCEEDED` |
| `build-for-testing` | `TEST BUILD SUCCEEDED` |

新規テストは、15 と 26 のバンドル ID の選択、解決できないときの非表示、既知の入口がない OS での非表示、固定パスを保存しないことを確認する。

## 未検証

- macOS 15 で `com.apple.launchpad.launcher` が Launchpad を指し、起動できること。
- macOS 26 以降で `com.apple.apps.launcher` を開いたときに、アプリ一覧が画面に表示されること。
- それぞれの macOS の標準 Dock と DockStudio の表示および動作が一致すること。
- macOS 27 以降でもバンドル ID が維持されること。
- VoiceOver など、画面上の操作とアクセシビリティ動作。

## 撮影の手順

画面確認と撮影は、専用のヘッドレス macOS VM または検証用 Mac のゲストで行う。ホストではアプリを起動しない。各 OS の標準 Dock にある入口と、DockStudio の項目を比較する。

1. macOS 15 と macOS 26 以降のゲストをそれぞれ用意する。
2. ゲストで DockStudio を起動し、`DOCKSTUDIO_DATA_DIR=<空の検証用ディレクトリ>` を指定する。既定のプロファイルを使う。
3. プロファイル編集の「項目を追加」を開き、macOS 15 では「Launchpad」、macOS 26 以降では「アプリ一覧」が出ることを確認する。
4. 項目を Dock に追加して保存し、DockStudio の Dock から開く。標準 Dock の Launchpad または Apps も開き、一覧の表示を比較する。
5. 標準入口の URL 解決ができない環境では、追加メニューと Dock の双方に当該項目が出ないことを確認する。

撮る画像は、OS ごとの追加メニュー、項目を追加した Dock、実際に開いた一覧、標準 Dock の入口を含む比較画面とする。操作の遷移を記録するときは、メニューから追加して一覧を開くまでを動画にする。
