# 最小化エフェクト設定の案内

## 変更内容

「設定」画面の Dock 設定に、最小化時の効果を変更する場所を追加した。案内では、アップルメニューから「システム設定」>「デスクトップとDock」>「Dock」へ進む手順を示す。

Apple のユーザガイドでは、macOS 15 の項目名は「ウインドウをしまうときのエフェクト」、macOS 26 の項目名は「ウインドウをしまうときのアニメーション」となる。両バージョンで異なる表記を案内し、Dock Studio からこの効果を変更できないことも明記した。

## 仕様上の判断

調査 Issue #25 では、最小化の実行は Accessibility で可能だが、効果の種類を選ぶ公開 API は見つからず、効果は OS に委譲する方針になっている。非公開 API は使用せず、設定画面からシステム設定へ利用者を案内する。

macOS 15 と 26 の項目名は、それぞれの Apple サポートガイドに合わせた。実際の設定アプリで表示名を確かめた記録はない。

## 撮影の手順

撮影する場合は、専用のヘッドレス macOS VM のゲストだけで行う。ホストではアプリを起動しない。

### 起動用データ

ゲストに空のディレクトリ `/Users/Shared/dockstudio-119` を用意する。初回起動時に作られる既定のプロファイルを使い、アプリを次のように起動する。

```sh
DOCKSTUDIO_DATA_DIR=/Users/Shared/dockstudio-119 /path/to/DockStudio.app/Contents/MacOS/DockStudio
```

### 確認する操作

1. Dock Studio の管理画面で「設定」タブを開き、Dock の「動作」に追加した案内文を表示する。
2. 案内に沿ってシステム設定の「デスクトップとDock」を開き、Dock の最小化設定名を確認する。macOS 15 では「ウインドウをしまうときのエフェクト」、macOS 26 では「ウインドウをしまうときのアニメーション」と表示されることを確認する。
3. 標準 Dock にあるアプリのウインドウを最小化し、選択中の効果で標準 Dock にしまわれることを確認する。Dock Studio の案内が効果を変更する操作を含まないことも確認する。
