# 外観機能レビューへの対応

[Sonnet のレビュー全文](SWIFTUI_REVIEW.md)は、コード変更の区切りで1回実施した。実行確認を含まない静的レビューであり、修正と実機確認は本体が行った。原文の件数表示には誤りがあるため、以下は見出しの全26項目を対応表に含めている。

| 項目 | 対応と根拠 |
|---|---|
| B1 | 画面端まで復帰領域を広げた。負の座標を含む幾何テストと、実機の画面下端で確認した |
| B2 | キーウィンドウにできるパネルと、メニューバーからの操作経路を追加した。折りたたみ要素に AX action を付け、VoiceOver 有効時は自動非表示を抑止する。Tab と Return による Finder 起動を実機確認した |
| B3 | 項目間隔を0にし、各セルの余白も hover 領域に含めた。セル間を移動しても拡大状態を保持する |
| N1 | 置き換え成功後に旧画像を削除する。保存先の backgrounds 直下にある UUID 名の PNG だけを削除対象にする。原画像の保護と掃除をテストした |
| N2 | 取り込み時の縮小処理をバックグラウンドに移した。表示用キャッシュは失敗も記憶し、更新日時の確認を毎秒1回までに制限した |
| N3 | アイコンのキャッシュキーを URL と加工種別にし、フレームごとの stat を除いた。アプリ起動と終了時にキャッシュを更新する |
| N4 | 通常表示は元の多解像度 NSImage を使う。加工は最大76pt×2倍×画面倍率を確保し、sRGB で描画する。Retina で通常、白黒、ガラス調を撮影した |
| N5 | 描画失敗時に OSLog を残し、フォールバックも呼び出し側でキャッシュする |
| N6 | 純関数に加え、CGContext を通した画像で色と alpha を検証した |
| N7 | 画像を余分に広げてぼかしてから、角丸で切り抜く |
| N8 | システム素材でぼかしを切った場合は、単色として描画する。角丸は共通定数にした。macOS 26 の実表示で角丸と背景モードを確認した。macOS 15 の素材は未検証である |
| N9 | 起動中の点に黒い輪郭を付け、スペーサーに影を付けた |
| N10 | URL などの SF Symbols にも白黒とガラス調を適用する |
| N11 | 名前をパネル内に収める位置に置き、重複する help を除いた |
| N12 | 縦配置の厚みを最大アイコンサイズから計算する。76pt×2倍の境界値をテストした |
| N13 | パネルに8ptの余白を足し、影の半径と向きを調整した |
| N14 | 10Hz のタイマーは Dock 表示中かつ自動非表示有効時だけ動かす。透過部分の判定はマウスイベントも使う |
| N15 | macOS のアクセシビリティ設定変更通知を購読した |
| N16 | 推測によるタイムアウトは追加しない。正規の begin と end 通知を数え、負数を防ぐ。時間だけで追跡を解除すると、長時間メニューを開いたままの操作を隠してしまうためである。通知が欠ける現象は未再現であり、実際に発生した場合は通知経路を調べる |
| N17 | orderFront の直後にも透過部分の判定を更新する |
| N18 | 起動中状態を名前とともに AX ラベルへ含め、空の AX value を除いた。折りたたみ要素に操作を付けた。時計の時刻も AX value へ含める。AXAttributedDescription で名前を読めることを確認した |
| N19 | スライダーと色選択は一時値で表示し、300ms のデバウンスで保存する。操作終了とアプリ終了でも保存する。保存失敗時は以前の値へ戻す |
| N20 | GPUI 試作と同じキーと enum 値を使う。保存前に読み込み時の生データと照合し、ロックで同時更新を防ぐ。未知キーは外観だけを読み取り専用にする。保存先を移動した場合は管理画像名から参照を復元する。競合、破損、移動のテストを追加した |
| N21 | 倍率の比較に accuracy を指定した。画像の取り込み、掃除、幾何、縦方向の寸法、実描画、保存競合を追加でテストした |
| N22 | body 内で表示項目と起動中アプリの Set を一度だけ計算する |
| N23 | macOS 15 を最小対象とし、NSGlassEffectView は macOS 26 で分岐する。Release ビルドを確認した |

レビューは再実行していない。修正後の実行結果と、実施できなかった確認は[検証報告](SWIFTUI_VERIFICATION.md)に記載する。
