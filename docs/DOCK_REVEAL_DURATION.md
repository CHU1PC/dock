# Dock の表示アニメーションの時間

## 仕様

設定画面の「Dock」に、表示アニメーションの時間を追加した。「使用していないときに隠す」を有効にすると、0〜1秒の範囲で、0.01秒ずつ調整できる。0秒では移動とフェードを省いて即時表示する。既定値は従来と同じ0.22秒になる。

時間は、既存の自動非表示設定と同じく全プロファイルに共通になる。`DockSettings.revealAnimationDuration` として保存し、設定を含むバックアップでも復元する。以前の保存データやバックアップに項目がない場合は、0.22秒で読み込む。保存データの範囲外の値と非有限値は拒否する。

隠れるアニメーションは従来の0.22秒のままになる。非表示にするまでの待ち時間と、画面端の反応範囲も変えていない。アプリの「アニメーションを減らす」と、macOS の「視差効果を減らす」は従来どおり優先する。

スライダーの操作中は一時値を使い、操作終了時または最後の変更から300ms後に保存する。キーボード操作も後者で保存する。終了直前に未保存の一時値があれば、保存してから終了する。保存に失敗した場合は、終了を取り消す既存の処理に従う。

## 検証

2026-10-17 に、以下を確認した。

| 項目 | 結果 |
| --- | --- |
| Release ビルド | 成功した |
| 自動テスト | 82件すべて成功した |
| 従来の保存データとバックアップ | 新しい項目がなくても0.22秒で読み込めた |
| 0秒、0.22秒、1秒 | 保存、再読込、バックアップ復元で保持された |
| プロファイルの切替 | 時間が共通設定として保持された |
| 不正な時間 | 負数、1秒超、無限大、NaNが保存を置き換えなかった |
| スライダーの一時値 | 操作終了まで保存値を変えず、丸めた値を確定できた |
| キーボード操作相当の連続変更 | 最後の値がデバウンス後に保存された |
| 保存に失敗する保存先 | 確定処理が失敗を返し、保存済みの設定を変更しなかった |

GUI は macOS 26.6.2、1600×1000の専用ヘッドレス VM 内で確認した。ホストのデスクトップには、アプリや VM の画面を表示していない。

- 新しい項目のない設定で起動し、画面に0.22秒と表示された。
- スライダーの両端を操作し、画面と保存ファイルで0秒と1秒を確認した。
- 1秒に設定して終了し、再起動後の設定画面にも1秒が表示された。
- Dock が隠れた状態から、0秒の即時表示と、1秒で上がってくる動きを撮影した。ポインタを離した後の退避も確認した。
- 実行ファイルの SHA-256 が、ホストの最終 Release ビルドと VM で一致した。

検証した実行ファイルの SHA-256 は `e637d779115dfd293ce63d4917ea5945aac515957ca9a94a99ca455a36797993` になる。ソースの機能部分は `59cbfa9` に対応する。

[画面と動画](media/dock-reveal-duration/)には、変更前の設定画面、初期値、0秒、1秒の設定画面と、比較動画を保存した。変更前は PR #5 の `17f7e13` に対応するビルドになる。比較動画は、前半6秒が0秒設定、後半6秒が1秒設定になる。それぞれ非表示、表示、再度の非表示を示す。撮影時刻の間隔を維持して15fpsに変換し、倍速にはしていない。VM の撮影であり、実機での所要時間や描画性能の測定ではない。

撮影前には、Dock のキーボードフォーカスを外し、実際に非表示になったことを確認した。フォーカスによって表示が維持された初回の動画と、macOS のデスクトップ表示中の動画は、比較の証拠に使っていない。

## レビューへの対応

Sonnet のレビューを1回実施した。確定した欠陥の指摘はなく、実行時の懸念が2件あった。以下を対応し、テストと最終ビルドを実行した。再レビューは行っていない。

| 指摘または補足 | 対応 |
| --- | --- |
| スライダーの変更ごとに同期保存が走る | アイコンサイズと同じ一時値とデバウンスを使い、操作終了時にも確定するようにした。終了時の確定も追加した |
| 浮動小数点の計算で上端が1秒をわずかに超える可能性がある | UI の入力を小数点以下2桁に丸め、0〜1に収める。保存データの検証は厳密なままにした。端の丸めをテストした |
| VoiceOver が有効な場合は自動非表示が無効になる | 既存の安全な操作を維持した。時間の設定値は保存する |
| 表示方向と Reduce Motion は実表示でも確認が必要になる | 下端配置の0秒と1秒を VM で確認した。左右配置、Reduce Motion と VoiceOver の組合せ、macOS 15〜25、実機での描画は今回の GUI 検証には含まない |
