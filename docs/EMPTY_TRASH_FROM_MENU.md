# Trash メニューからゴミ箱を空にする

## 変更内容

Trash 項目のコンテキストメニューに「ゴミ箱を空にする…」を追加した。選択後に対象範囲と永久削除を説明する確認を表示し、承認された場合だけ Finder にゴミ箱を空にするよう依頼する。

消去対象は Finder が管理するユーザーのゴミ箱である。Finder がロックされた項目を確認する場合は、その確認に従う。キャンセルは失敗として扱わず、処理中はメニューに処理中の表示を出し、重複実行を止める。Finder の Apple Events 操作が拒否された場合は、システム設定で Dock Studio から Finder の操作を許可する案内を表示する。

## 仕様判断

- Finder の `empty trash` AppleScript コマンドを使う。アプリから `.Trash` 以下を直接削除しないため、Full Disk Access を追加で要求しない。
- Finder の操作には macOS の Automation 許可が必要になる。許可が拒否された場合は、権限を設定する場所を示す。
- 確認文でゴミ箱内の全項目が永久削除されることを示す。標準 Dock の Option 操作に相当する確認省略は実装しない。
- Finder がロックされた項目を検出した場合、その確認を Finder に任せる。キャンセルやほかの Finder エラーは消去結果として区別する。
- AppleScript の実行結果とエラー番号の対応は `TrashEmptyService` に集め、実行クロージャーを差し替えてテストする。

## 撮影の手順

専用ヘッドレス macOS VM のゲストだけで行う。普段使いのホストにはアプリや Dock を表示しない。ゲストの使い捨てデータディレクトリを作り、次の内容を `profiles.json` に保存する。実際の利用者データを使わず、消去してもよい検証用項目だけを入れる。

```json
{
  "schemaVersion": 1,
  "activeProfileID": "00000000-0000-0000-0000-000000000001",
  "settings": { "mode": "custom", "position": "bottom", "iconSize": 64, "autoHide": false, "showRunningApps": false },
  "profiles": [
    {
      "id": "00000000-0000-0000-0000-000000000001",
      "name": "Empty Trash demo",
      "items": [
        { "id": "00000000-0000-0000-0000-0000000000a1", "name": "Calculator", "kind": "application", "target": "file:///System/Applications/Calculator.app/" }
      ]
    }
  ]
}
```

ゲスト内でデータディレクトリの `.Trash` に、通常項目とロック項目を含む使い捨てファイルを作る。アプリは次のように起動する。

```sh
DOCKSTUDIO_DATA_DIR=/Users/Shared/empty-trash-demo /path/to/DockStudio.app/Contents/MacOS/DockStudio
```

1. Custom Dock の Trash 項目を右クリックし、「ゴミ箱を空にする…」を選ぶ。
2. 確認文がゴミ箱内の全項目と取り消せない永久削除を示すことを記録する。
3. キャンセルを選び、項目が残ることを確認して撮影する。
4. 再度メニューを開いて確認し、承認する。Finder の Automation 許可ダイアログが出た場合は許可する。
5. 通常項目を含むゴミ箱が空になり、アイコンが空の状態へ変わることを確認する。処理中表示が見えれば、その状態も撮影する。
6. ロック項目だけを入れて再度実行する。Finder のロック項目確認が出た場合は、キャンセル時に項目が残り、削除を選んだ場合に永久削除されることを確認する。
7. macOS のシステム設定で Dock Studio から Finder の Automation を拒否した状態でも試し、Dock Studio が設定場所を案内することを撮影する。
8. Option キーを押しながらメニューを操作しても、Dock Studio の確認が出ることを確かめる。

撮影する画像と動画は次のとおり。

- 画像: 「ゴミ箱を空にする…」が表示された Trash メニュー。
- 画像: 全項目の永久削除を説明する確認画面。
- 画像または動画: キャンセル後も検証用ファイルが残っていること。
- 動画: 確認、承認、Finder の許可、消去完了、Trash アイコンの変化。
- 画像: Automation を拒否したときの明確な権限案内。
- 画像または動画: Finder のロック項目確認と、キャンセルまたは削除の結果。
- 画像: Option キーを使った場合にもアプリ側確認が出ること。

## 標準 macOS Dock との比較で記録すること

専用 VM の標準 Dock で、同じ種類と数の検証用ファイルを使って比較する。比較表には、メニュー項目の名称と順序、確認が出る条件と文言、確認に表示される対象範囲、キャンセル後に項目が残るか、承認後に消える項目数、ロック項目の確認と結果、Option キーで確認を省略できるかを記録する。アプリ側と標準 Dock の永久削除結果に差がある場合は、その差も記録する。
