# Dock Studio — GPUI

Custom Dock、設定、プロファイル編集を Rust と GPUI で実装しています。macOS 15 以降を対象にします。

## 起動

Rust と Xcode の開発環境が必要です。リポジトリのルートで実行します。

```bash
gpui/scripts/run.sh
```

管理画面から「Dock を表示」を選ぶと、独立した Dock を表示します。起動時には Dock を自動表示しません。Apple Dock の設定とデスクトップの壁紙は変更しません。

開発用のアプリバンドルを作る場合は、次を実行します。署名と公証を済ませた一般配布用ビルドではありません。

```bash
gpui/scripts/build-app.sh
```

## 設定

- 左、下、右への配置、表示先、アイコンサイズ、自動非表示を設定できます。
- 背景はシステムの素材、単色、画像、完全透明から選べます。色、不透明度、ぼかしを設定できます。
- アイコンは通常、白黒、透けた単色のガラス調から選べます。
- ホバー拡大と起動中の点を切り替えられます。「動きを減らす」と macOS のアクセシビリティ設定を尊重します。
- macOS 26 以降では利用可能な場合に NSGlassEffectView を使います。macOS 15 では NSVisualEffectView に切り替えます。

## データと macOS 連携

既存の Swift モデルと保存処理を、別プロセスのヘルパーとして呼び出します。プロファイルと下書きは既存の形式を使います。外観は同じフォルダの appearance.json に保存します。外観ファイルを読み込めない場合は、元のファイルを保護して外観の保存を停止します。

プロファイルのエクスポートには既存の配置設定が含まれます。新しい外観設定は現在の Mac に保存し、このエクスポートには含めません。

ファイル選択、読み込みと書き出し、起動対象の確認は macOS 標準のダイアログを使います。取り込み時の対象一覧と設定復元の選択は GPUI 側で表示します。

## 検証と撮影

```bash
gpui/scripts/test.sh
gpui/scripts/capture.sh
```

撮影では、一時保存先を使ってウィンドウを画面外に配置します。ユーザーのデスクトップに管理画面と Dock を表示せず、各画面とホバー・非表示の状態変化を記録します。出力先を省略すると一時ディレクトリを使います。ffmpeg があれば動画も作成します。マウス操作の録画ではありません。

GPUI が SwiftUI より軽いという性能の保証はしていません。実際のデスクトップ上の応答、複数画面の抜き差し、フルスクリーン、macOS 15 と Intel Mac での確認は残ります。

テキスト入力には GPUI 同梱例を改変して使っています。[第三者ライセンスの表示](NOTICE.md)を参照してください。

同じ保存先は、同時に一つの GPUI セッションだけが編集できます。旧 SwiftUI 版が起動している間も、プロファイルの編集を停止します。旧版を終了すると保存済みデータを読み直します。

## アクセシビリティと常駐

管理画面を閉じてもアプリは常駐します。メニューバーの Dock Studio から、設定、Dock の表示、プロファイル切替、終了を選べます。Dock の右クリックにも同じ操作があります。

Tab と Shift-Tab で操作対象を移動できます。ボタンは Enter または Space で実行できます。GPUI 0.2.2 は AX ツリーを提供しないため、VoiceOver には未対応です。これは既存 SwiftUI 版からの既知の退行であり、全面移行の完了条件として残っています。

[レビューへの対応](REVIEW_FIXES.md)と[移行の進捗](../docs/GPUI_MIGRATION.md)を参照してください。

画面ロック中は WindowServer から画像を取得できません。撮影コマンドはロック状態を検出して停止します。Mac のロックを解除してから再実行してください。
