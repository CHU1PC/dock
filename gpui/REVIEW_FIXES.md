# レビューへの対応

[レビュー原文](REVIEW.md)の全 29 件を確認した。実装の修正は以下のとおりである。実デスクトップで未確認の動作と、VoiceOver の退行は残っているため、完成版としては扱わない。

| 指摘 | 対応 |
| --- | --- |
| B1 | NSWindow の frame 更新を main queue に送った。GPUI の描画中の借用が終わってから、サイズ変更のコールバックを受ける。撮影時にも同じ処理を使い、NSView と GPUI の viewport の一致を検査する。 |
| B2 | 独自のメニューを廃止し、NSMenu の選択結果を GPUI に渡す。画面を表示しない検査で、選択からコマンドまでを確認した。親要素の mouse down による消失をなくした。 |
| B3 | 対話操作の前にヘルパーを前面化する。独自の確認と背景選択には modalPanel のレベルを指定する。GPUI 側にはダイアログをキャンセルする操作を加えた。処理中の終了要求は、処理が終わるまで保持する。 |
| B4 | 管理画面を閉じる操作を、非表示に変更した。NSStatusItem を追加した。メニューバーと Dock の右クリックから、プロファイルを直接選べるようにした。 |
| M1 | システム素材に単色の tint を重ねない。システム素材の不透明度は、ネイティブの素材側で適用する。 |
| M2 | 表示項目と起動中の ID を Swift が返す。既存の正規化とシンボリックリンク解決を引き継いだ。 |
| M3 | 自アプリの bundle ID とプロセス ID を除外する。起動中アプリと画面情報を、1 秒ごとに更新する。 |
| M4 | リンクの名前、http または https、ホストをヘルパーで検査する。入力側も事前に検査する。成功時に入力欄を初期化する。 |
| M5 | 「メインに追従」と、未接続のディスプレイの表示を追加した。画面情報の更新間隔を 1 秒に短縮した。画面変更通知による即時更新は、今後の改善として残る。 |
| M6 | 保存と復旧などの status を、管理画面の下部に表示する。 |
| M7 | 定期更新では入力を無効にしない。操作中に来たユーザー要求は、キューに保持して順番に実行する。 |
| M8 | Dock を表示した時点で、非表示までの待ち時間をリセットする。 |
| M9 | NSMenu をポインタ付近に出す。macOS に画面内への配置を任せ、Dock の viewport による見切れをなくした。 |
| M10 | 排他制御、旧版の起動、データ破損を、別の理由として表示する。「読み込み直す」でロック取得を再試行する。定期更新で同じエラーを再表示しない。 |
| M11 | ボタンと項目に Tab の停止位置とフォーカス表示を追加した。Enter と Space でボタンを実行できる。GPUI 0.2.2 の AX ツリー未対応による VoiceOver の退行は未解決であり、移行文書と PR に明記する。 |
| M12 | 撮影モードを DockView のフィールドにした。配置の寸法、当たり判定、自動非表示の判定を純関数に分離し、テストを追加した。撮影でも本番と同じ寸法計算と frame 更新を使い、画面外への原点移動だけを行う。 |
| M13 | 拡大しても viewport の長さを変えない。ポインタを 100ms ごとに確認し、領域を離れたらホバーを解除する。時計以外の不要な定期再描画を抑える。 |
| L1 | 背景画像のパスを backgroundPath に分離した。status をファイル名に使わない。 |
| L2 | 未使用変数を削除した。 |
| L3 | 項目の削除後に選択を解除する。 |
| L4 | 削除される項目と未保存の編集を確認文に示す。アプリ本体と参照先のファイルは消えないことも示す。最後のプロファイルは、確認を出さずに削除できない理由を返す。 |
| L5 | 読み取り専用の場合は、Dock の切り替えを停止する。 |
| L6 | Rust の Settings は未知フィールドを保持する。Swift が扱えない将来の設定項目を保存ファイルに見つけた場合は、読み取り専用にしてファイル全体を保護する。 |
| L7 | プロファイル名、選択状態、Dock の表示状態が変わったときにだけ、メニューを作り直す。 |
| L8 | 参照先の変更日時でネイティブのキャッシュを更新する。Rust 側も PNG の変更日時で再読込する。削除済み項目のキャッシュと、上限を超えた描画キャッシュを解放する。 |
| L9 | 透明な背景を除き、すべての背景で「透明度を下げる」を尊重し、ぼかしを無効にする。 |
| L10 | 色コードを 6 桁の ASCII 16 進文字に制限する。 |
| L11 | 通常起動の失敗は NSAlert に表示する。検証用の CLI と撮影では stderr に出力する。 |
| L12 | 時計の詳細ウィンドウを再利用する。閉じた場合だけ作り直す。 |

## 残る確認

- 実デスクトップで、右クリックメニュー、メニューバー、ダイアログ、ウィンドウを閉じた後の常駐を確認する。
- click-through、Spaces、全画面、画面の抜き差しを確認する。
- 日本語 IME を使い、定期更新と連続操作の最中の編集を確認する。
- macOS 15 と Intel Mac で確認する。
- ホバー時の CPU、GPU、メモリ、応答時間を測る。
- VoiceOver の操作経路を実装する。現状は、既存 SwiftUI 版を残している。

再レビューは実行していない。加藤さんの規則に従い、コードの区切りごとのレビューは Sonnet の 1 回だけにした。
