# レビュー指摘への対応

## 方針

レビュー指摘はすべて確認して対応する。項目ごとの修正確認は挟まない。この方針をルートの CLAUDE.md と AGENTS.md に記載した。レビューは再実施せず、修正した内容をテストとビルドで確認した。

## 観測された指摘

| 指摘 | 対応 | 確認 |
| --- | --- | --- |
| 通常起動でも Dock タイルが有効になる | 試用フラグがある場合だけ起動する | 通常起動の delegate が Dock メニューを返さないことを確認した |
| 既存プロファイルを選べない | 保存済み設定を読み取り、メモリ内にコピーする。設定がない場合と壊れた場合には、サンプルであることを詳細画面に表示する | 設定を編集しても元ファイルが変わらず、下書きも作られないことを確認した |
| 古いエラーで誤ったアラートが出る | 操作前にエラーを消し、今回のエラーだけを取り出して消費する | 成功時に古いエラーを返さず、失敗時のエラーが残らないことを確認した |
| 未開始でも「一時停止」と表示する | 開始前とリセット後を「待機」にする | 開始前、経過、完了、リセットを確認した |
| 画像の縦横比と実機記録 | 正方形の256×256pxに修正した。実機記録は未実施である | 実際の標準 Dock 上の撮影は、表示許可の返答待ちである |
| 撮影スクリプトの堅牢性 | find を使い、ビルド用一時ディレクトリを終了時に消す。既定の出力先を一時ディレクトリにする。進捗文書を更新する | 撮影スクリプトを実行して確認した |

プロファイルの選択は試用データだけを切り替える。標準 Dock の配置と独立した Custom Dock の表示は変更しない。選択中の名前とこの制約を詳細画面に表示する。

## 仮説への対応

| 指摘 | 対応と限界 |
| --- | --- |
| 背景でタイマー更新が遅れる | 実行中だけ ProcessInfo の activity を保持し、停止と完了時に解除する。スリープは許容し、復帰通知で再描画する。残り時間は壁時計から再計算する。App Nap と実機スリープ復帰の確認は残る |
| 開いたメニューの表示が古くなる | refresh 時に現在のメニューの表示と選択状態を更新する。メニューを保持したまま完了させるテストを追加した |
| 試用モードでもメニューバー項目が残る | 試用モードでは MenuBarExtra を挿入しない |
| 詳細画面と controller が循環参照する | 操作コールバックを弱参照に変更した。詳細ビューが controller を保持しないことを確認した |
| 古い activate API を使う | activate() に変更した。macOS 15 を対象とするビルドで確認した |

## テスト範囲

追加した回帰テストは、通常起動、保存済み設定のコピー、サンプル表示の説明、メニューの更新、プロファイル切り替えのエラー、停止と再開始、詳細ビューの参照、待機状態と長時間後の残り時間を確認する。

```bash
swift test --scratch-path /tmp/dockstudio-headless-tests
xcodebuild -quiet -project DockStudio.xcodeproj -scheme DockStudio -configuration Debug -destination 'platform=macOS,arch=arm64' -derivedDataPath /tmp/dockstudio-native-derived CODE_SIGNING_ALLOWED=NO build
```

macOS 26.5.2、Apple Silicon、Xcode 26.6 で56件のテストが成功した。アプリのビルドも成功した。管理画面と独立した Custom Dock は表示していない。

## 残る確認

標準 Dock 上での縮小表示、右クリック操作、クリック時の詳細表示、背景動作とスリープ復帰は未確認である。macOS 15 と Intel Mac での実機確認も残る。そのため PR は Draft のままとする。

## 2026-10-17 の実機確認

標準 Dock の表示、コンテキストメニュー、クリック時の詳細画面、背景でのカウントダウンを確認した。詳細画面を閉じると終了する問題を修正した。58 件の自動テストとビルドが成功した。復帰通知の処理もテストした。詳細は [実機確認の記録](VERIFICATION.md)に記載した。以前の「表示許可待ち」は解消した。macOS 15、Intel Mac と物理的なスリープ復帰は、未確認の範囲として残る。
