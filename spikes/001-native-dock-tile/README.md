# 標準 Dock のアイコン表示の試作

## 目標と方針

標準 Dock の見た目と操作を保ちながら、アプリ自身のアイコンで時計と集中タイマーを使えるか確認する。公開 API の NSDockTile と applicationDockMenu を使う。独立した Custom Dock の表示や標準 Dock の配置変更は、この試作の確認対象に含めない。

## 計画

1. 時計と集中タイマーを描画する Dock タイルと、右クリックメニューを実装する。
2. アイコンだけで起動する試用モードと、クリック時の小さな詳細画面を用意する。
3. メモリ内の試用データで動かし、通常の設定への影響を避ける。
4. テスト、ビルド、描画の記録、コードレビューを実施する。

## 進捗

描画、メニュー、試用モードを実装した。テストとビルドは成功した。レビュー指摘の修正を実装した。標準 Dock 上の表示と操作、閉じた後の常駐を実機で確認した。試作の表示設定とタイマーは終了時にリセットする。

## 試し方

リポジトリのルートで次を実行する。ビルド後に、標準 Dock に Dock Studio のアイコンが表示される。

```bash
spikes/001-native-dock-tile/run.sh
```

アイコンを右クリックすると、時計とタイマーの表示切り替え、開始、一時停止、リセットができる。アイコンをクリックすると小さな詳細画面が開く。管理画面と独立した Custom Dock は、起動時に表示しない。

試用モードは保存済みのプロファイルを読み取り、メモリ内のコピーを使う。保存済み設定がない場合や読み込めない場合は、サンプルであることを詳細画面に表示する。選択しても標準 Dock の配置は変更しない。終了は右クリックメニューの「Dock Studio を終了」から行う。試作のタイマーと既存の Custom Dock のタイマーは独立している。
